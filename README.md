# двусвязные списки

Реализация библиотеки двусвязных списков на си двумя способами:
- с помощью массива структур (list.*)
- с помощью указателей (list_ptr.*)

Первая реализация использует realloc на size * 2 при нехватки памяти для хранения текущего двусвязного списка,
а вторая - calloc каждого элемента списка

массив - push & pop(0):
```
                  mean ±     σ    min …   max
  Wall Time [s]  2.063 ± 0.050  2.015 … 2.177
  Memory [GiB]     2.4 ±   0.0    2.4 …   2.4
```
указатели - push & pop(0):
```
                  mean ±     σ    min …   max
  Wall Time [s]  3.423 ± 0.067  3.360 … 3.542
  Memory [GiB]     3.0 ±   0.0    3.0 …   3.0
```
Реализация с помощью массива быстрее в 1.5-2 раза в зависимости от операций.

Это происходит из-за накладных расходов на calloc и free при работе с указателями

# Возможности
- Две реализации двусвязного списка с одинаковым использованием.
- Операции: push, insert, remove, get, print
- Встроенный верификатор списка и графический дамп

# Структура проекта
- main.c - демо-программа
- list.h && list.c - реализация списка на массиве структур
- list_ptr.h && list_ptr.c - реализация списка на указателях
- common.h &*& common.c	- общие функции
- log.h / log.c	- логи
